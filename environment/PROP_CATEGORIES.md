# KOKLER Prop Categories

Every procedural prop should have a purpose before it is added to a room.

## Structural

Columns, support beams, masonry blocks, stairs, drains, arches, braces, and collapsed ceiling pieces. These can block movement when large.

## Navigation

Numbered stones, chalk marks, hanging threads, route stakes, distinct pillars, broken signs, and doorway carvings. These should help the player remember where they are.

## Interactive

Root Shrines, map tables, survey points, map fragments, levers, sealed doors, and future Cartographer Mark points. These need a silhouette, prompt, or restrained local emphasis.

## Narrative

Father notes, abandoned bedrolls, broken packs, measuring tools, old bones, storage containers, and damaged tablets. These should imply one small event, not explain a whole lore page.

## Hazard

Unstable roots, fungal growth, collapsing stone, spore vents, narrow root obstructions, and corrupted floor patches. These must preserve readable movement and combat lanes.

## Reward

Sealed storage niches, map fragment stands, weapon remains, root clusters, and survey caches. These should be visible and reachable.

Collision rule:

- Full blocking: columns, large rocks, walls, wells, large furniture, large roots.
- Soft blocking: visible knee-high debris, medium mushrooms, small crates, root knots.
- Decorative: paper, rope, chalk, tiny stones, bones, floor cracks, thin roots.
